# Project Screenshots

Real captures from the running system. Every number visible in these is computed output from
real data on disk. Neither is a mockup.

| File | What it shows |
|---|---|
| `01-voyage-desk-verdict.png` | The decision half of the Voyage Desk for a real 75,000 t Newcastle AU to Paradip thermal coal lot on a 30 day term: the WAIT verdict, today's rate against the walk-away line, the value of waiting, the exercise boundary over 4,000 simulated paths, and the written reasoning behind all of it. |
| `02-route-exploration-and-risk.png` | The route half of the same quote: all 16 route and repositioning options the solver evaluated, mapped and ranked, with the chosen Supramax pairing and ballast leg marked; plus the flagged remarks covering the Malacca Strait transit drop, Bay of Bengal cyclone climatology, and the vessel-class rate disclosure. |

## Naming convention

`NN-short-description.png`, numbered in the order they appear in the main `README.md`.

Neither screenshot contains passwords, API keys, tokens or personal credentials.
